> **一句话结论**：这个算法/方案解决什么问题、核心思路是什么、适合谁用。

## 背景与动机

- 要解决的问题场景
- 为什么现有方案不够用（性能？成本？效果？）

## 核心思路

- **算法流程**：一步步讲清楚（伪码 / 流程图描述）
- **关键公式/模块**：讲原理，不堆公式（需要的才给）
- **复杂度**：时间/空间/显存/推理成本

## 实现要点

- 工程细节：参数、数据准备、与现有框架怎么接
- 踩坑提醒：复现时最容易出问题的地方

## 效果与数据

| 场景 | 指标 | 该方案 | 对比方案 |
|---|---|---|---|
|   |   |   |   |

- 在什么条件下效果最好、什么条件下会退化

## 适用边界与取舍

- 适合什么场景、不适合什么场景
- 与该方向其他方案的对比取舍（为什么选它/不选它）
