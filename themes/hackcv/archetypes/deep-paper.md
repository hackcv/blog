> **一句话结论**：这篇论文解决了什么问题、效果如何、是否值得精读。

## 要解决的问题

- 背景：这个问题为什么重要、现状如何
- 痛点：现有方法（基线）的不足在哪里，越具体越好

## 方法拆解

- **核心思路**：用一段话讲清楚作者的核心洞察
- **关键模块**：按模块/步骤拆解（结构、公式、伪码）
- **与基线差异**：对比现有方法，新在哪里

## 实验与数据

| 数据集/任务 | 指标 | 本文 | 基线 | 提升 |
|---|---|---|---|---|
|   |   |   |   |   |

- 消融实验说明了什么
- 有没有值得注意的细节（训练配置、数据清洗等）

## 局限与点评

- 作者自己承认的局限
- 论文没说的/可能被忽视的问题
- 对从业者的实际价值：什么场景适用、什么场景别用

## 复现要点

- 代码/权重地址、环境要求、显存/算力量级
