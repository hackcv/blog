# About hackcv

hackcv is an AI news aggregation and summarization platform.

## Philosophy

Let AI help filter and summarize information, so you can focus on what truly matters.

## Features

- 🤖 AI-curated global AI/tech news
- 📝 Smart summaries for quick insights
- ⚡ Clean reading experience, no ads
- 📱 Responsive design

## Tech Stack

- Hugo static site generator
- AI content curation & summarization
- Modern minimalist theme
