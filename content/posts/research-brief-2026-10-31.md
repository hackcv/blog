## 一、arXiv 最新 AI 论文（2026.10.29-10.31）

### 1. Proactive Memory for Event-Driven LLM Agents

**摘要**：主动式 LLM Agent 需要从持续观测与历史中预判服务机会。现有方法偏重近期上下文或简单检索相关记忆，难以验证反复出现的行为规律、并判断其是否适用于当前事件。本文提出 Proactive Memory（ProactMem），将历史组织为近期事件、时间轨迹与行为规律三层；轨迹事实回源校验、规律经历史回放评估后才匹配当前条件，并在自建纵向基准 ProactiveStream 上验证。
**领域**：LLM Agent / 主动记忆
**推荐理由**：把「何时该主动出击」做成了可量化基准（整体 F1 52.6%，相对最强基线 +21.4%），而非靠 prompt 拍脑袋；对做智能客服/个人助理「主动触达」能力的团队是直接的方法底座。
**链接**：https://arxiv.org/abs/2610.36967

### 2. Reproducible Evaluation as the Substrate for Safe Prompt Compression in Production Agents

**摘要**：在生产环境评测操作实时可变企业数据的对话 Agent 很难：回放会话会因后端状态漂移而失真，基准会随数据移动悄悄失效。本文提出一个在实时数据变化下仍保持可复现的离线评测 harness，并把它当作 GEPA 式提示优化的适应度函数，加一道正确性闸门防奖励黑客；在商家侧 Agent 上把完整提示面压缩 3.5-7.6% 而不回退任务正确性。
**领域**：Agent 工程 / 提示优化 / 评测
**推荐理由**：给出「压提示≠降质量」的可落地方案，且跨三个模型家族一致成立——长上下文成本压力下，能安全瘦身提示的团队有直接的钱可省。
**链接**：https://arxiv.org/abs/2610.31972

### 3. The Trust-Agreement Gap in Repeated Multi-Party LLM Negotiation

**摘要**：LLM Agent 越来越多地代表个人或组织参与谈判，却在重复多方互动中易受操纵。本文引入重复、多方、多议题的谈判框架，让一个参与方暗中阻止达成一致；每轮后 Agent 维持两两信任估计并带入后续谈判，对比「信任感知」与「信任无关」策略。
**领域**：多智能体 / 博弈与谈判
**推荐理由**：揭示一个反直觉结论：信任感知 Agent 能在几轮内识别对手，但准确信任估计只有在其被显式纳入决策时才转化为 +23 个百分点的达协议率——对部署自治谈判/采购 Agent 的团队提示「有信任模型」不等于「用得好」。
**链接**：https://arxiv.org/abs/2610.31971

### 4. Certified Execution Harness for Agentic AI: Safe and Least-Intrusive Petri-Net Supervisory Control

**摘要**：研究 LLM Agent 在提示注入下的安全工具执行问题。用 Petri 网把 LLM 与工具之间的执行 harness 形式化为监督控制：库所（place）代表能力、审批与预算，只有前置条件齐全的变迁才触发；被注入的请求若前置未满足或预算已耗尽，无论措辞如何都被拒绝。并引入 replanning 闭环刻画「被拒后重试」的代价。
**领域**：AI 安全 / Agent 执行控制 / 形式化方法
**推荐理由**：把「工具调用安全带」从规则清单升级为可证明的安全监督，且给出「最小侵入」的优化刻画——对金融/运维等高风险自主 Agent，是比 prompt 护栏更硬的一层。
**链接**：https://arxiv.org/abs/2610.31376

### 5. BrickWright: Agentic Creation of Physically Feasible Brick Builds

**摘要**：提出一个智能体框架，从自然语言或图像出发生成物理上可拼搭的积木造型：用分层规划分解结构、在拼搭约束下做几何可行性验证，并迭代修正不稳或 impossible 的连接，输出可被真实积木复现的搭建指令。
**领域**：具身智能 / 智能体内容生成 / 几何约束
**推荐理由**：把「生成式设计」推进到「生成物可被物理实现」这一步，是 CAD/教育/玩具自动化里「设计-制造闭环」的轻量示范，也提示多模态 Agent 该把物理约束当一等公民。
**链接**：https://arxiv.org/abs/2610.31651

### 6. Gate3DGen: A Pre-processing Model that Selectively Purifies Real-World Images for 3D Generation

**摘要**：真实世界图像常含遮挡、杂乱背景与不一致光照，直接喂给 3D 生成会污染几何与纹理。Gate3DGen 是一个预处理模型，选择性地「净化」输入图像——筛掉干扰、补全被遮挡区域、统一光照，再交给下游 3D 生成，从而提升重建一致性与保真度。
**领域**：3D 生成 / 图像预处理 / 计算机视觉
**推荐理由**：把「脏输入→干净 3D」的脏活单拎出来做成可插拔模块，比端到端硬扛更符合工程直觉；对从手机照片一键出 3D 的应用是直接增益。
**链接**：https://arxiv.org/abs/2610.31649

### 7. SyncVid: World-Equivariant Diffusion for Synchronized Video Generation

**摘要**：从单条参考视频生成多视角动态场景，需要在视角间与时间上同时保持一致。SyncVid 不在每个 2D 图像平面独立采样噪声，而是把单目视频提升为规范化 4D 表示、把噪声与场景几何及未观测空间关联，再光栅化到任意目标相机；并提出跨视角一致性白化去除像素局部相关。无需改架构，以 LoRA 适配预训练视频扩散模型。
**领域**：视频生成 / 多视角一致性 / 扩散模型
**推荐理由**：从「噪声源头」而非「网络结构」强制时空与跨视角一致，思路干净且易迁移；对虚拟拍摄、数字孪生多机位合成是实用的新基线。
**链接**：https://arxiv.org/abs/2610.31765

### 8. OmniRay: Camera-Agnostic Monocular 3D Reconstruction with Composite Ray Fields

**摘要**：提出与相机型号无关的单目 3D 重建方法，用复合光线场（composite ray fields）统一表达不同内参与镜头畸变下的射线，从而让同一模型跨设备、跨镜头泛化，无需为每种相机单独标定或重训。
**领域**：单目 3D 重建 / 神经渲染 / 计算机视觉
**推荐理由**：把「换相机就要重来」的痛点用射线场统一消解，对消费级设备（手机/AR 眼镜）上即拍即重建的泛化部署很有价值。
**链接**：https://arxiv.org/abs/2610.31645
