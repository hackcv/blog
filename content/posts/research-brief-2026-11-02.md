## 一、arXiv 最新 AI 论文（2026.10.31–11.02）

### 1. Learning a Single Token to Replace Long System Prompts in LLMs（BE-Token）

**摘要**：长系统提示在推理时反复占用上下文且低效。作者提出轻量训练框架，学习一个行为等价 Token [BE]：先用重建把原系统提示语义编码进单 token，再把下游行为蒸馏进去；无需改动预训练权重、无需辅助压缩模型、无需标注回复。在三个数据集上，用单个 [BE] token 替代最长约 3,000 token 的提示，压缩比达约 3000×，同时保留原提示约 98% 的下游表现。
**领域**：大语言模型 / 提示压缩 / 推理效率
**推荐理由**：把「冗长系统提示」压成一个可训练 token，几乎释放整段上下文给用户输入与输出，对高并发、长提示的 Agent 系统是直接可复用的降本手段，且零权重改动、易落地。
**链接**：https://arxiv.org/abs/2511.23271

### 2. Time Series Forecasting via Reasoning: A Slow-Thinking Approach with Reinforcement Fine-Tuned LLMs（Time-R1）

**摘要**：多数时序预测仍走「快思考」范式，缺乏显式推理与可解释中间步骤。论文提出 Time-R1：先用监督微调做预热适配，再用强化学习以奖励驱动推理优化提升泛化；引入细粒度多目标奖励，以及 GRIP（基于组的相对重要性策略优化）用非均匀采样鼓励有效推理路径探索。在多个数据集上取得有竞争力的预测表现。
**领域**：时间序列预测 / 强化学习 / 大语言模型
**推荐理由**：把「慢思考」推理训练进时序模型，并用多目标奖励 + 采样策略解决领域错位与分布外泛化，为金融、能源、交通等依赖预测决策的场景提供了可解释的新路线（CIKM 2026）。
**链接**：https://arxiv.org/abs/2506.10630

### 3. Unleashing the Power of LLMs in Dense Retrieval with Query Likelihood Modeling（LLM-QL）

**摘要**：稠密检索是 RAG 与生成增强的基础，但 LLM 作为解码器常因不看后续 token 而难以捕捉全局信息。受经典查询似然（QL）模型启发，作者把 QL 最大化作为辅助任务强化骨干，再驱动对比学习；引入注意力阻断（AB）与文档破坏（DC）两个组件。在 MS MARCO（域内）与 BEIR（域外）上均优于其他 LLM 检索器。
**领域**：信息检索 / 稠密检索 / 大语言模型
**推荐理由**：用经典 IR 思想（QL）补 LLM 检索器的全局视野短板，域内域外双优，且代码开源，对做 RAG 召回质量的团队是低成本可抄的基线（CIKM 2026）。
**链接**：https://arxiv.org/abs/2504.05216

### 4. Mind the Couch! Eliciting MLLM Reasoning in Interior Design via Weak-to-Strong Task Vector Injection（DART-I）

**摘要**：多模态大模型在室内设计这类密集约束空间常因高频细节丢失而幻觉、碰撞。论文提出 DART-I：用极轻量弱专家从图像抽取连续的空间距离与色彩排版特征，经线性投影转成方向性任务向量，作为残差动态注入冻结 MLLM 的潜空间，无需微调即可锚定因果推理。在多个基准验证有效（ACM MM 2026）。
**领域**：多模态大模型 / 空间推理 / 室内设计
**推荐理由**：不改权重、用「弱到强」确定性先验做潜空间干预，绕开昂贵微调与灾难性遗忘，给垂直场景（设计、空间规划）落地 MLLM 提供了一条低成本的精准推理路径。
**链接**：https://arxiv.org/abs/2608.23242

### 5. ThinkingGuard: Decoding Implicit Hazards via Step-by-Step Risk Attribution in Multimodal LLMs

**摘要**：多模态隐式风险（各自无害的文本与图像逻辑汇聚诱发不安全输出）难被现有检测发现。作者先构建 TriggerBench（5600 实例，首个显式建模风险组合性的数据集），再用分步监督结构化推理框架训练专用守卫模型 ThinkingGuard：借鉴情境感知理论把隐式风险识别拆成递进认知阶段，用步奖励 MCTS 探索最优轨迹并双约束偏好对齐（ACM MM 2026）。
**领域**：多模态安全 / 风险检测 / 大模型对齐
**推荐理由**：针对「跨模态逻辑汇聚」这类最难防的隐式风险，给出数据集 + 训练框架的完整方案，而非单模态捷径学习，对把 MLLM 放进医疗、金融等安全敏感域有直接价值。
**链接**：https://arxiv.org/abs/2609.36562

### 6. Do We Really Need Multimodal Emotion Language Models Larger Than 1B Parameters?（Light-MER）

**摘要**：多模态情感识别（MER）随 MLLM 能力提升，但常伴随参数膨胀（≥7B）导致端侧难部署。论文挑战「更大更好」，提出 Light-MER：用知识蒸馏把强教师知识迁移到 sub-1B 学生，引入切片 Wasserstein 距离 + 隐状态对齐的最优传输损失，以及基于 GRPO 的多奖励优化平衡性能与效率。九个基准上达 SOTA 且推理效率显著提升（ACM MM 2026）。
**领域**：多模态情感识别 / 模型蒸馏 / 端侧部署
**推荐理由**：把 MER 模型压到 1B 以下还维持 SOTA，正好回应机器人、手机等资源受限场景的实时部署诉求，也用实验质疑了「越大越好」的惯性。
**链接**：https://arxiv.org/abs/2607.12787

### 7. Line-Coupled Language Model（LCLM）

**摘要**：标准自回归每步只生成一个 token，并行解码常因未来 token 强依赖而困难。LCLM 在每个解码步并行预测所有活跃文本行的下一个 token，把多行 token 交错成单一因果序列、用按行错位的旋转位置编码保留时序与因果。881M 参数下平均每前向生成 2.94 个内容 token（基线 1.00），损失仅略升；即使每步生成 16 token，损失也只高 0.09。
**领域**：大语言模型 / 并行解码 / 推理加速
**推荐理由**：用「按行错位」巧妙把并行生成塞进标准因果注意力，无需额外训练期 token 流量，每前向 2.94× 吞吐量且精度几乎不掉，是推理加速的一个干净思路。
**链接**：https://arxiv.org/abs/2609.07129

### 8. Bayesian Network Structure Discovery Using Large Language Models（PromptBN / ReActBN）

**摘要**：传统贝叶斯网络结构学习依赖大量观测数据、计算贵。论文提出统一框架把 LLM 放到中心：无数据时用 PromptBN 仅用元数据查询 LLM 高效发现有效概率关系；有观测数据时用 ReActBN 把 ReAct 推理范式与 BIC 等结构分数结合迭代精炼，LLM 全程在环。实验显著优于现有 LLM 方法与数据驱动算法，尤其在低/无数据场景（TMLR）。
**领域**：贝叶斯网络 / 结构学习 / 大语言模型
**推荐理由**：把 LLM 从「预处理工具」升级为结构发现的核心，且能在少数据/无数据场景工作，对因果发现、领域知识建模这类数据稀缺任务很有吸引力。
**链接**：https://arxiv.org/abs/2511.00574
