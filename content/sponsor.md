# 投放说明

hackcv 是一个非商业化优先的站点：没有弹窗、没有信息流广告、没有信息排序干预。站内唯一的商业化位置是文章末尾的「本期工具推荐」。

## 我们推荐什么

- 只推荐本站**实际使用或亲手验证过**的工具与服务（如本站服务器所在的云厂商、日常在用的大模型 API 平台）
- 推荐位带「推广 · 含返佣链接」标注，符合《互联网广告管理办法》对互联网广告可识别性的要求
- 链接统一使用 `rel="sponsored nofollow"`，不影响内容排序与搜索权重

## 推荐位规则

- 每篇文章文末最多展示一个推荐位，按天轮换
- 推荐内容与文章内容相互独立，撰写与排序不受投放影响
- 读者可通过各平台阅读器的「显示原文」或浏览器扩展屏蔽推广脚本，不影响正文
